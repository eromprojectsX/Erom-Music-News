# Erom Music — Novidades

Esta pasta é o local para organizar as novidades e os arquivos atualizados do Erom Music.

## Como usar

- Adicione aqui os arquivos novos do projeto.
- Preserve os arquivos originais antes de substituir qualquer coisa.
- Não envie músicas protegidas por direitos autorais sem autorização.
- Nunca inclua senhas, tokens, chaves de API ou credenciais.

## Observação

Criar esta pasta não publica nem implanta automaticamente o aplicativo.
